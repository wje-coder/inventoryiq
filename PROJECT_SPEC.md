## InventoryIQ Project Specification

## Phase 1: Project Foundation

Phase 1 must deliver:

1. A FastAPI backend skeleton
2. A React and TypeScript frontend skeleton
3. PostgreSQL configuration
4. Dockerfiles for the backend and frontend
5. A Docker Compose configuration
6. Environment variable templates
7. Backend and frontend health checks
8. Initial automated tests
9. Formatting, linting, and type checking
10. A GitHub Actions workflow
11. An updated README with local setup instructions

## Phase 1 Acceptance Criteria

Phase 1 is complete when:

1. The backend starts successfully
2. The frontend starts successfully
3. PostgreSQL starts successfully
4. The backend can connect to PostgreSQL
5. The health endpoint returns a successful response
6. Backend tests pass
7. Frontend tests pass
8. Docker Compose starts the complete local stack
9. No secrets are committed
10. Setup instructions are documented

Claude must complete Phase 1 only and stop for review before beginning another phase.
